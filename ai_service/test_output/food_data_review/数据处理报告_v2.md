## 一、处理概述

本次处理从开源项目《中国食物成分表标准版（第6版）》数据中提取关键字段，**根据食物分类控制字段可见性**，简化后供审核。

### 1.1 核心设计理念

并非所有营养字段对所有食材都有意义。例如：

- **GI值**：对主食、蔬菜、水果、豆制品、奶类、零食有意义；对肉类、水产、油脂类无意义
- **叶酸**：对主食、蔬菜、豆制品、水产有意义（尤其深绿蔬菜与动物肝脏/海鱼）；对水果、奶类、肉类无意义
- **DHA**：仅对水产类（海鱼）有意义；其他食材几乎不含DHA

### 1.4 show_gi / show_folic_acid / show_dha 标记说明

这三个布尔字段用于控制前端是否显示对应的营养指标：

- **show_gi = True**：前端应显示GI值列
- **show_gi = False**：前端应隐藏GI值列（显示 '-'）
- **show_folic_acid = True**：前端应显示叶酸列
- **show_folic_acid = False**：前端应隐藏叶酸列
- **show_dha = True**：前端应显示DHA列
- **show_dha = False**：前端应隐藏DHA列

以下字段因非核心营养指标，已从处理结果中移除：

## 三、审核要点

### 3.1 需要重点审核的问题

1. **GI值缺失**：需显示GI值的食材中，部分没有匹配到GI数据，需确认是否接受此现状
2. **热量数据**：部分记录热量为0或缺失，需确认数据质量
3. **字段可见性矩阵**：请审核GI/叶酸/DHA的可见性规则是否符合预期
4. **分类准确性**：基于文件名的自动分类可能不完全准确，建议抽查
5. **叶酸/DHA数据**：这两个字段在开源数据中不存在，建议先保留为空，后续从专业数据源补充

### 3.2 建议的审核流程

1. 查看Excel文件中的"数据概览"sheet，确认总体统计
2. 查看"分类分布与字段可见性"表，确认可见性规则
3. 切换到"食物数据"sheet
4. 筛选"需要审核"列为"是"的记录
5. 抽查各分类下的代表性食物，确认分类和字段可见性正确
6. 确认数据质量无误后，再考虑导入数据库
